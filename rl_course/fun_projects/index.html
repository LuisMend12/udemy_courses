Both build out from the back. They part company in midfield — Arsenal circulates, PSG goes vertical — and again in the final third, where Arsenal shoots and PSG dribbles. Nobody told either side to do that.

One accent, spent only on the primary action. Club colours are data, not decoration — they never appear on a control.

Type ramp
Display 26/600
Heading 17/600
Body 15/400 — the default reading size.
Meta 13/400 for supporting copy.
Mono 11.5 · paths, keys, numbers

Five steps, and size alone carries the hierarchy — weight and colour only reinforce it.

Button states
Primary

Every button is a container with a hard bottom edge. Hover lifts it 1px, press flattens it to 0 — the response is the confirmation. Disabled is grey and flat, the shape everyone already reads as "not now".

Principles applied
  • PrioritiseOne featured slot at a size nothing competes with; everything else is a uniform tile.
  • AttentionColour, size, space, proximity and movement, one at a time — the accent, the hero, the stat cluster, the running ball.
  • LanguageGlyphs on a 24px grid at one stroke weight; buttons with shadow and highlight so they read as pressable.
  • ConventionX closes, grey means disabled, a padlock means locked, Esc backs out.
  • ConsistencyOne token set shared with the match page, so moving between them never feels like leaving.
  • FeedbackPress compresses, hover lifts, copy confirms with a toast, focus is always visible.
